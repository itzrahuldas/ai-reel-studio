# Contributing to AI Reel Studio

First off, thank you for considering contributing to AI Reel Studio!

## Development Workflow

1. Check out the [Architecture Document](docs/ARCHITECTURE.md) to understand how the system works.
2. We use AI Agents to help build and maintain this project. Check out .agents/agents.md to see the defined personas.
3. If you're adding a feature, please read docs/PRODUCT_SPEC.md first.

## Setting Up Locally

See the [README.md](README.md) for detailed instructions on using Docker Compose to spin up the entire stack.

## Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface, this includes new environment variables, exposed ports, useful file locations and container parameters.
3. Update docs/CHANGELOG.md with your changes.
4. You may merge the Pull Request in once you have the sign-off of two other developers, or if you do not have permission to do that, you may request the second reviewer to merge it for you.
