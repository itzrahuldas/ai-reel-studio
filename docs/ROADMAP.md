# Roadmap — AI Reel Studio

**Version:** 0.1.0
**Last Updated:** 2026-05-03

---

## MVP (v0.1 — Current)

**Goal:** Working end-to-end pipeline for single users

- [x] Project scaffolding & documentation
- [x] Agent system & workflow definitions
- [ ] Full AI generation pipeline (LLM + TTS)
- [ ] FFmpeg rendering (static image fallback)
- [ ] Review & approval UI
- [ ] Instagram OAuth connection
- [ ] Instagram Reels publishing
- [ ] Docker Compose local dev environment
- [ ] Basic authentication (JWT)
- [ ] Single workspace per user

---

## Beta (v0.2)

**Goal:** Reliable, polished product for early adopters

- [ ] Real AI video generation (Runway / Luma integration)
- [ ] Regeneration of individual sections (caption, hashtags, script)
- [ ] Caption rich-text editor
- [ ] Hashtag suggestions with engagement metrics
- [ ] Project history & version comparison
- [ ] Email notifications (job complete, publish failed)
- [ ] Basic usage analytics (generations/month)
- [ ] Improved error messages and retry UI
- [ ] Mobile-responsive frontend

---

## V1 (v1.0)

**Goal:** Production-ready for small teams and agencies

- [ ] Multi-user workspaces with roles
- [ ] Scheduled publishing (choose date/time)
- [ ] Multiple Instagram accounts per workspace
- [ ] Brand kit (logo, color palette, font preferences)
- [ ] Custom voice selection for TTS
- [ ] Storyboard visual editor
- [ ] Asset library (reuse uploaded images)
- [ ] API key / webhook for integration partners
- [ ] GDPR compliance (data export, deletion)
- [ ] Stripe billing integration
- [ ] Usage limits per plan tier

---

## V2 (v2.0)

**Goal:** Multi-platform and agency-scale

- [ ] TikTok publishing integration
- [ ] YouTube Shorts publishing integration
- [ ] Multi-platform simultaneous publish
- [ ] Content calendar view
- [ ] Post performance analytics (IG Insights API)
- [ ] AI style presets (viral hooks, storytelling formats)
- [ ] Bulk generation (10 reels from one session)
- [ ] Multi-language content A/B testing
- [ ] Collaboration comments on reel versions
- [ ] Custom domain for white-label

---

## Agency Features (v3.0)

**Goal:** Power features for social media agencies

- [ ] Client workspaces (agency manages multiple clients)
- [ ] Client approval portal (client-facing review link)
- [ ] White-label branding
- [ ] Custom AI persona per client
- [ ] Bulk export (ZIP of all assets)
- [ ] Content reporting for clients
- [ ] Reseller pricing tiers
- [ ] SSO (SAML / Google Workspace)
- [ ] SOC 2 Type II compliance path
