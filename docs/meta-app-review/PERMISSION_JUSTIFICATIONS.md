# Permission Justifications

AI Reel Studio should request only the permissions that are demonstrated by the
reviewer flow. The app does not access Instagram DMs, comments, ads, Page post
management, Business Manager administration, or unrelated Page data.

## Recommended Permission Set

Request these permissions for the current Instagram Business/Creator publishing
flow:

- `instagram_basic`
- `instagram_content_publish`
- `pages_show_list`

Do not request these permissions:

- `instagram_manage_comments`
- `instagram_manage_messages`
- `ads_management`
- `business_management`
- `pages_manage_posts`
- `pages_manage_metadata`

## Conditional Permission

`pages_read_engagement` should be requested only if the deployed OAuth/API flow
truly requires it to read Page metadata while resolving the linked Instagram
Business account. AI Reel Studio does not display Page engagement metrics or Page
insights. If Page lookup works with `pages_show_list` alone, mark
`pages_read_engagement` as "do not request yet" and remove it from the OAuth
scope list before final review.

## instagram_basic

### Why AI Reel Studio Needs It

AI Reel Studio uses this permission to identify the Instagram Business or
Creator account connected through Meta OAuth and to display basic account
metadata in the app.

### Where It Is Used In The UI

- `Dashboard` > `Integrations`
- Connected Instagram account card
- `Dashboard` > Reel detail page > `Instagram Publishing`

### Reviewer Step That Demonstrates It

1. Log in to AI Reel Studio.
2. Go to `Dashboard` > `Integrations`.
3. Click `Connect`.
4. Complete Meta OAuth.
5. Confirm the Integrations page shows the connected Instagram username and
   account type.

### Data Accessed

- Instagram professional account ID
- Instagram username
- Instagram account type

### Data Stored

- Instagram user ID
- Instagram username
- account type
- connection status
- granted scopes

### Data Not Accessed

- DMs
- comments
- followers list
- private messages
- ads data
- unrelated Instagram account data

### Retention And Security Notes

The app stores only the metadata needed to show the connection and publish to the
selected account. OAuth tokens are encrypted at rest and are never returned to
the frontend or shown in logs.

### User Benefit

The user can verify which Instagram professional account is connected before
publishing a Reel.

## instagram_content_publish

### Why AI Reel Studio Needs It

AI Reel Studio uses this permission to publish a rendered MP4 Reel to the user's
connected Instagram Business or Creator account through the Instagram content
publishing flow.

### Where It Is Used In The UI

- Reel detail page
- `Video Preview`
- `Instagram Publishing`
- `Publish Now`
- `Schedule`
- `Publish History`

### Reviewer Step That Demonstrates It

1. Create a Reel from a test prompt.
2. Render the Reel into an MP4.
3. In `Instagram Publishing`, select the connected account.
4. Click `Publish Now`, or schedule a future publish.
5. Confirm `Publish History` shows the job status and media ID after publish.

### Data Accessed

- connected Instagram professional account ID
- rendered MP4 public HTTPS URL
- caption and hashtags chosen/generated by the user
- publish container status
- published media ID after successful publish

### Data Stored

- publish job ID and status
- Instagram media container ID
- Instagram media ID
- publish timestamps
- error message if publishing fails

### Data Not Accessed

- Instagram comments
- Instagram DMs
- ads data
- audience insights
- arbitrary user media libraries
- unrelated Page content

### Retention And Security Notes

Publish jobs are stored so users can see whether a publish succeeded, failed, or
is scheduled. The token used for publishing is decrypted only on the backend
worker at publish time. Tokens are not logged.

### User Benefit

The user can create content once in AI Reel Studio and publish or schedule the
finished Reel directly to Instagram without manually downloading and uploading
the MP4.

## pages_show_list

### Why AI Reel Studio Needs It

AI Reel Studio uses Facebook Page access to find Pages available to the Facebook
test user and resolve the Instagram Business or Creator account linked to the
selected or available Page.

### Where It Is Used In The UI

- Meta OAuth permission prompt
- `Dashboard` > `Integrations`
- Connected account card showing the linked Page name

### Reviewer Step That Demonstrates It

1. Click `Connect` on the Instagram integration.
2. In Meta OAuth, grant Page access to the test Facebook Page.
3. Return to AI Reel Studio.
4. Confirm the connected account card shows the linked Page name and Instagram
   professional account.

### Data Accessed

- Facebook Page ID
- Facebook Page name
- linked Instagram Business account reference

### Data Stored

- Page ID
- Page name
- linked Instagram account ID

### Data Not Accessed

- Page posts
- Page comments
- Page messages
- Page ads
- Page insights or engagement metrics
- Pages not granted during OAuth

### Retention And Security Notes

The Page ID/name are stored only to show which Page links to the Instagram
professional account and to help the user troubleshoot the connection. The app
does not publish to Facebook Pages.

### User Benefit

The user can connect the correct Instagram Business or Creator account through
the required Facebook Page relationship.

## pages_read_engagement - Conditional / Do Not Request Yet By Default

### Why AI Reel Studio Might Need It

The current backend Page lookup uses Meta's Page account lookup to resolve
`id`, `name`, and `instagram_business_account`. If the deployed OAuth/API flow
requires `pages_read_engagement` for that Page metadata, request it and explain
that it is used only for Page lookup during Instagram connection. If the Page
lookup succeeds with `pages_show_list` alone, do not request this permission.

### Where It Is Used In The UI

- Meta OAuth permission prompt, only if requested
- `Dashboard` > `Integrations`, only to show the linked Page name after OAuth

### Reviewer Step That Demonstrates It

1. Click `Connect` on the Instagram integration.
2. Grant Page access in Meta OAuth.
3. Confirm the app can resolve the linked Facebook Page and Instagram Business
   or Creator account.

### Data Accessed

- Page ID
- Page name
- linked Instagram Business account reference

### Data Stored

- Page ID
- Page name

### Data Not Accessed

- Page engagement metrics
- Page insights
- Page feed content
- Page comments
- Page messages
- Page post creation or management

### Retention And Security Notes

If requested, use this permission only for Page metadata needed by the
Instagram-account connection flow. Do not use it for insights or analytics until
the UI and reviewer flow demonstrate that feature.

### User Benefit

The user can connect the correct Instagram professional account when Meta's Page
lookup requires this permission for the linked Page metadata.
